# Credit Risk Platform

A platform that takes a loan application PDF and produces a full underwriting assessment — risk score, fraud flags, SHAP explanation, and a structured report — all in one flow.

Built as a personal project to learn how credit decisioning pipelines work in practice, using real LendingClub data and modern ML tooling.

---

## What it does

Upload a loan application PDF and the platform runs through these steps automatically:

1. **Reads the document** — extracts text natively or via OCR if scanned
2. **Pulls out structured fields** — applicant name, income, loan amount, FICO, DTI, etc.
3. **Prepares model features** — maps the extracted fields into the 123 features the model expects
4. **Scores the application** — XGBoost model trained on 391K LendingClub loans predicts the probability of default
5. **Checks for fraud signals** — 13 deterministic rules flag income inflation, FICO inconsistencies, thin-file patterns, and more
6. **Routes the application** — a credit policy engine decides: Decline / Refer / Manual Review / Auto Approve
7. **Explains the score** — SHAP waterfall shows which factors drove the result
8. **Writes the report** — an LLM generates a structured 4-section underwriter narrative
9. **Exports to PDF** — formatted A4 report with colour-coded verdict

The model hit **ROC-AUC 0.742** on the test set. The LLM only summarises findings — it never makes the credit decision.

## Running locally

You'll need a conda environment with Python 3.12.

```bash
git clone https://github.com/priyanshu-projects/credit_risk_platform
cd credit_risk_platform
pip install -r requirements.txt
```

Create a `.env` file with your API keys:

```
GEMINI_API_KEY=your_key_here
OPENAI_API_KEY=your_key_here
```

Then run:

```bash
streamlit run app/Home.py
```

The trained model file (`models/xgboost_baseline.joblib`) and the processed feature metadata need to exist for the risk scoring page to work. These are generated by running the training notebook in `notebooks/`.

```
src/
  document_ai/        PDF reading and field extraction
  features/           Feature engineering
  risk_models/        Model training and prediction
  fraud/              Fraud detection rules
  rules/              Credit policy engine
  explainability/     SHAP utilities
  reports/            LLM report generation and PDF rendering
models/               Trained model files
notebooks/            Training and analysis notebooks
sample_documents/     Sample loan PDFs for testing
```

## Data

Trained on the [LendingClub loan dataset](https://www.kaggle.com/datasets/wordsforthewise/lending-club) (2007-2018). Target variable: Fully Paid vs Charged Off. Dataset not included in the repo due to size.
